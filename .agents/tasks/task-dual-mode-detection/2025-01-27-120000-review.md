# Dual-mode emotion detection with face tracking (v1)

This change splits the emotion detector into two operating modes - Snapshot (captures a photo with a poem overlay when emotions are detected) and Contador (counts and registers only). Face tracking via center-point proximity prevents re-counting the same person while they remain in frame. A live stats card shows unique person count during detection, poems are served per-emotion in Spanish, and the dashboard gains a CSV export endpoint.

**Verdict**: NEEDS_CHANGES

## Issues (5)

1. **Counter reset on brief face loss** - `uniquePersonCountRef` drops to 0 after just 3 seconds without any detected face. The unique person count should persist across tracking resets. Decouple the cumulative unique count from the tracking array lifetime so momentary gaps do not wipe the session total.

2. **Detection pauses during snapshot overlay** - The detection loop early-returns when `isSnapshotActive` is true, meaning no database captures occur for the 5-second snapshot window. Continue the detection loop (skip canvas drawing and snapshot triggers) so database saves still happen during the overlay.

3. **Unbounded CSV export** - `allCaptures` loads the entire filtered dataset into memory with no `LIMIT`. Add a reasonable limit (e.g., 10000 rows) to prevent OOM on serverless functions.

4. **Snapshot re-triggers after tracking reset** - Because all face IDs and `snapshotShownForFacesRef` reset after 3 seconds of absence, the same person leaving and returning triggers a new snapshot. Do NOT clear `snapshotShownForFacesRef` during the tracking reset. Keep it for the session lifetime.

5. **`onPersonCount` reference stability** - `updateTracking` depends on `onPersonCount` which is an inline arrow in the parent. Wrap `onPersonCount` in `useCallback` in the parent (`page.tsx`) to prevent unnecessary effect teardowns.

## Additional minor issue

6. **Single-face confidence gap** - The 50% confidence gate only applies when `faces.length > 1`. A single face with very low confidence can trigger a snapshot. Add a minimum confidence threshold (e.g., 0.3) for single-person snapshots too.
